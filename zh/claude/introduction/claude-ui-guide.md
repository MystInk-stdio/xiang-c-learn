# Claude 介面功能解析

剛開始用 Claude 的時候，介面上有很多按鈕不知道是做什麼的。

這個頁面用互動式方式呈現 Claude Chat 的完整介面——**將游標移到任何一個按鈕上**，就會看到這個功能的說明。

<ClaudeUIDemo />

## 功能區域總覽

| 區域 | 說明 |
|------|------|
| 左側欄 | 對話歷史、新增對話、帳號設定 |
| 頂部列 | 模型切換、對話分享、更多操作 |
| Tab 列 | Chat / Core Work / Code 三種對話模式 |
| 對話區 | 訊息來回、複製、重試、評分功能 |
| 輸入區 | 傳送訊息、上傳檔案、語音、延伸思考 |
