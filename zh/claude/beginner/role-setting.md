# 角色設定：讓 Claude 變成你的專屬助理

角色設定是 Prompt 技巧裡 CP 值最高的一招。一句話告訴 Claude 它是誰，輸出品質立刻提升。

## 為什麼角色設定有效？

Claude 被訓練成可以模仿各種專業人士的思考模式。當你說「你是一個資深電商顧問」，Claude 會自動調整：
- 用電商業界的術語
- 考慮轉換率、客單價等實際指標
- 給出可以直接執行的建議

## 角色設定的三個層次

### 基本：職位標籤
```
你是一個電商文案寫手。
```

### 進階：加上背景與專長
```
你是一個有 5 年蝦皮賣場經驗的電商顧問，
專精於 3C 配件類商品的文案優化。
```

### 專業：加上行為指引
```
你是一個有 5 年蝦皮賣場經驗的電商顧問，
專精於 3C 配件類商品的文案優化。
回覆時：
- 先問清楚商品的核心賣點
- 給出 3 個文案選項讓我挑選
- 每個選項說明適合哪種情境
```

## 常用角色模板

- `你是一個台灣市場的行銷顧問`
- `你是一個熟悉 YouTube SEO 的內容策略師`
- `你是一個有 Shopee 賣場優化經驗的電商顧問`
- `你是一個台灣大學生可以看懂的科普作家`
