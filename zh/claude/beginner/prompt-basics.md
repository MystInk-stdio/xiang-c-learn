# Prompt 基礎入門

**Prompt** 是你給 Claude 的指令，也就是你在對話框輸入的那段文字。

## 為什麼 Prompt 這麼重要？

同樣一個問題，問法不同，答案品質差非常多。

**差的 Prompt：**
> 幫我寫文案

**好的 Prompt：**
> 幫我寫一段 100 字的蝦皮商品標題，產品是 iPhone 16 螢幕保護貼，訴求是防爆防指紋，目標受眾是在意手機外觀的大學生，語氣輕鬆活潑。

## Prompt 的四個核心要素

1. **任務**：你要 Claude 做什麼
2. **背景**：相關的上下文資訊
3. **格式**：輸出要長什麼樣子
4. **限制**：不能做什麼、字數限制等

## 實際練習

下次對 Claude 提問時，試著加上這個結構：

```
任務：[你要的結果]
背景：[相關資訊]
格式：[輸出格式]
限制：[額外條件]
```
