## Claude 入門｜三大工具怎麼用？

Claude 是目前臺灣企業相當愛用的 AI 工具之一。它不僅擁有強大的長文脈絡理解能力，產出的文案、主題或腳本也比較不像 ChatGPT 或 Gemini 那樣充滿「AI 味」，讓使用者不需要花太多時間大幅修改。

Claude 目前有三個主要的使用入口：**Chat、Cowork、Claude Code**。

1. **Chat**：最基本的對話介面。有想法想驗證、問題想釐清，或是需要整理思緒時，直接在這裡問就對了。
2. **Cowork**：桌面應用程式，主要讓非開發者也能用自然語言處理日常繁瑣的檔案與任務自動化，不需要懂程式也能上手。
3. **Claude Code**：命令列介面的 AI coding agent，專門用來寫程式、debug、重構代碼，或是架設網站、開發應用程式，是工程類任務的核心工具。

## 我自己的使用方式是這樣：

每次有新想法，我會先在 Chat 裡請它幫我找出想法的盲區；確認可行之後，再請它輸出一份完整企劃，決定下一步行動。

如果當天有固定且重複的事務要處理，我會用 Cowork 讓它按照我設定的步驟自動執行。若是想架網站或寫 Python 腳本這類工程任務，則會切換到 Claude Code 來操作。
