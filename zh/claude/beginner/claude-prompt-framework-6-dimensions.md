進入 Claude，第一個碰到的就是 Chat 功能了。你是不是每次下完提示詞，Claude 給的結果都不是你要的？本篇文章將告訴你如何使用「正確的提示詞」。

過去我們在為 ChatGPT 或其他 AI 工具撰寫提示詞時，通常需要包含很多資訊，例如：

1. 角色設定：它必須充當什麼樣的角色
2. 目標確認：需要幫你完成什麼目標
3. 限制與注意事項：這個目標有哪些限制
4. 輸出格式：最後呈現的格式又是什麼

光是想這些提示詞，就浪費了你很多時間……

但放到 Claude 生態裡，完全不需要這麼複雜。正因為 Claude 的語言理解能力強，它能自動補足你沒說清楚的背景脈絡，所以你不需要過度包裝提示詞，只需要明確地告訴它你的想法就夠了。我把提示詞拆分成幾個維度：

**明確目標層級**

你要的是策略（方向）、戰術（執行步驟），還是評估（對錯判斷）？

範例：「幫我規劃 IG 內容策略」vs「幫我評估這個內容策略可不可行」→ 結果完全不同

**給定限制條件**

時間、預算、人力（你是 solo）；現階段資源（有什麼工具、帳號、數據）；不可動的前提（例如：「我不打算開廣告」）。這些限制條件，決定了 Claude 給你的建議是否真的能被你執行，而不是一份看起來很完整、但你根本做不到的計畫。

**說明當前現狀**

你在哪裡、做了什麼、目前結果如何。沒有現狀 = Claude 只能給通用建議，不是給你的建議。

**指定輸出格式**

要清單、要腳本、要比較表、要決策框架。不說格式 → Claude 自由發揮 → 你不一定會拿到你想要的東西。

**說明決策情境**

你在做「事前規劃」還是「事後檢討」？你是在「二選一」還是「從零開始構建」？

**點明你最怕什麼風險**

例如：「我怕燒時間」、「我怕文案寫了沒流量」、「我不想太早商業化」。這讓 Claude 知道要幫你規避什麼，而不只是告訴你怎麼做。

注意，這六個維度不需要每次全部填齊，依照你的任務類型，選用 2-3 個最關鍵的維度即可，填太多反而讓提示詞失焦。

所以下次在下提示詞的時候，你就可以按照這幾個維度去思考，如何讓 Claude 協助你解決想解決的問題，才不會一而再、再而三地重複修改提示詞。
